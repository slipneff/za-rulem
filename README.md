# 🚗 За рулём — обучающая платформа

Учим водить и **понимаем почему**, а не зубрим: механика машины простыми словами,
логика ПДД через «зачем это придумали», и все официальные экзаменационные билеты
ГИБДД 2026 с разбором каждого ответа.

## Что внутри

- **Механика машины** — сцепление, коробка передач, 4-тактный двигатель, тормоза/ABS,
  сцепление с дорогой и занос, механика vs автомат. С интерактивными анимациями.
- **Логика ПДД** — приоритет («помеха справа»), знаки, разметка, светофоры, регулировщик,
  скорость, обгон, остановка/стоянка, пешеходы, манёвры — каждое правило выводится из причины.
- **Путь к правам** — медсправка → автошкола → ГИБДД, план сдачи (в т.ч. гибрид/другой регион).
- **Билеты ПДД 2026** — 40 билетов × 20 вопросов (800), с картинками и официальными
  комментариями. Режимы: по билетам, по темам, случайная тренировка, экзамен-симуляция
  (правила 2026: 20 вопросов, +5 за ошибку, ≤2 ошибок), разбор личных ошибок.
- **Прогресс** — точность по темам, история экзаменов (хранится в браузере, localStorage).

## Интерактивные анимации (`widgets.js`)

`clutch` (сцепление), `gearbox` (коробка), `engine4` (4 такта), `brakes` (ABS),
`regulator` (регулировщик), `intersection` (помеха справа). Чистый SVG + Canvas-free
анимации, управляются ползунками/кнопками.

## Структура

```
index.html      каркас (sidebar + topbar + view)
styles.css      дизайн-система (тёмная «приборная» тема)
app.js          роутер, рендер уроков, движок экзамена, прогресс
widgets.js      интерактивные анимации механики/ПДД
content.js      обучающие уроки (window.CONTENT)
data/tickets.js официальные билеты 2026 (window.TICKETS_DATA)
assets/tickets/ картинки к вопросам (локально)
```

Без сборки и зависимостей — открывается как `file://` и одинаково работает за nginx.

## Запуск локально

```bash
python3 -m http.server 8137 --directory .
# открыть http://localhost:8137/
```

## Деплой (beelink, docker nginx)

```bash
bash deploy_beelink.sh    # пакует, заливает по scp, поднимает nginx:alpine на :8088
```
